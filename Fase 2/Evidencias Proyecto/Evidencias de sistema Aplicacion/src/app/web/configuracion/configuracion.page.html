Analítica

Cada pantalla que se abre en la web o en la app deja un evento con la ruta, la plataforma y la hora. Si hay sesión iniciada, también el usuario.

  • No se registran las pantallas de este panel.
  • No se registran datos personales ni escritos en formularios.
  • No se usan cookies de terceros ni servicios externos: los datos viven en la base del proyecto.
  • Sólo la cuenta con rol Administrador puede leerlos.
